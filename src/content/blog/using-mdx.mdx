Este tema incluye la integracion [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) instalada y configurada en `astro.config.mjs`. Si no necesitas MDX, puedes desactivarla al retirar esa integracion.

## Por que usar MDX

MDX es una variante de Markdown compatible con JavaScript y JSX. Permite [combinar componentes de interfaz con tu contenido](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro) para crear graficas, avisos y otros elementos especiales.

Si ya tienes contenido escrito en MDX, esta integracion facilita su migracion a Astro.

## Ejemplo

Asi puedes importar y utilizar un componente dentro de un archivo MDX:

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#">
	Componente integrado en MDX
</HeaderLink>
